# Brand_Name_Generator
welcome to my project, this is a python program which helps the user to generate his/her brand name by connecting their native and pet's name. 

How does the project works,
{
-Create a greeting for your program.
-Ask the user for the city that they grew up in and store it in a variable.
-Ask the user for the name of a pet and store it in a variable.
-Combine the name of their city and pet and show them their band name.
}
